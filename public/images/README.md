# Aset visual NKHS TENDA

## Koleksi Indonesia — aktif

19 gambar dibuat dengan **built-in image_gen** berdasarkan arahan pengguna tentang tenda dekorasi pernikahan Indonesia. Gambar adalah ilustrasi konsep AI, bukan foto dokumentasi NKHS TENDA atau karya vendor lain.

- `tents/classic-cream-wedding.jpg`, `modern-sage-wedding.jpg`, `rustic-wedding-tent.jpg`, `royal-premium-wedding.jpg`, `traditional-wedding.jpg`, `minimalist-white-tent.jpg`: tenda kain dengan pelaminan dan seating Indonesia. Hero memakai Classic Cream.
- `makeup/natural-bride.jpg`, `soft-glam-bride.jpg`, `modern-elegance.jpg`, `classic-beauty.jpg`, `paes-jawa.jpg`, `sunda-siger.jpg`, `hijab-bride.jpg`: ilustrasi berbeda untuk ketujuh kategori rias. Kartu, filter, detail, dan kalkulator memakai pemetaan data yang sama.
- `decorations/modern.jpg`, `garden.jpg`, `rustic.jpg`, `royal.jpg`, `jawa.jpg`, `sunda.jpg`: ilustrasi pelaminan masing-masing pilihan.

Prompt final lengkap dan jalur setiap aset tersimpan di [`docs/image-prompts.json`](../../docs/image-prompts.json). PNG keluaran tool dikonversi menjadi JPEG kualitas 82 untuk aset website. Aset asli hasil generasi tetap tersimpan di luar project; seluruh aset yang dipakai website sudah lokal di folder ini.

Detail adat dan hasil akhir rias dikonfirmasi melalui konsultasi. Furniture, pelaminan, dan bunga yang tampak pada gambar tenda tidak otomatis termasuk tarif tenda per m².
